# Security policy

## Reporting a vulnerability

Do not open a public Issue for a suspected security vulnerability or expose credentials, access tokens, private Drive links, or user data. Use GitHub's [private vulnerability reporting](https://github.com/stoptalkingishh/openquiz/security/advisories/new) for this repository. Include reproduction steps, affected URLs or files, impact, and a safe proof of concept.

We will acknowledge reports, investigate, and coordinate a fix before public disclosure when practical. Please allow reasonable time for a response before sharing details publicly.

## Supported version

The `main` branch and the current GitHub Pages deployment are supported. Keep dependencies current and never put secret values in `NEXT_PUBLIC_*` variables; values with that prefix are included in the browser build.
