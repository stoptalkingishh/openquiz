# Security+ content reference

## Acronyms & Essential Terms deck

`public/securityplus/secplus-acronyms.json` is original study content for the CompTIA Security+ SY0-701 objectives. It is a vocabulary review aid, not a representation of exam questions or a substitute for the current official exam objectives.

The deck groups its cards by the following objective areas:

| Objective area | Cards |
| --- | --- |
| 1.0 General Security Concepts | AAA through HMAC (1–18) |
| 2.0 Threats, Vulnerabilities, and Mitigations | APT through XDR (19–29) |
| 3.0 Security Architecture | IDS through RPO (30–43) |
| 4.0 Security Operations | SIEM through DRP (44–51) |
| 5.0 Security Program Management and Oversight | BIA through PCI DSS (52–60) |

Each card’s explanation identifies the related SY0-701 objective so learners can connect a term with the skill area in which it is commonly applied. The list is intentionally selective: it prioritizes high-value acronyms that are easy to confuse and complements the existing topic decks.

Use the current [CompTIA Security+ SY0-701 exam objectives](https://comptiacdn.azureedge.net/webcontent/docs/default-source/exam-objectives/comptia-security-sy0-701-exam-objectives-%286-0%29.pdf?sfvrsn=204179cc_6) as the authoritative reference. Verify the exam version and objectives with CompTIA before studying or scheduling an exam.
